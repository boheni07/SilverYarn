은빛실타래 화면설계서
웹(자서전 사용자·가족·관리자) & 모바일앱(당사자)

오프라인 우선 하이브리드 아키텍처를 기반으로 한 4개 사용자 축 — 모바일앱(당사자), 웹 자서전 사용자, 웹 가족, 웹 관리자 — 의 전체 화면을 정의합니다. 각 화면은 저충실도 와이어프레임과 요소별 설명, 이벤트 정의로 구성되며, 개발계획서의 Phase 1~3 로드맵과 매핑됩니다.

버전v1.2
발행2026년 9월
총 화면 수23개 (모바일 7 · 웹 16)
기준 문서기획서 v0.5 · 프로세스 흐름도 · BI가이드 v2.0
화면 ID 규칙
M = 모바일앱 · WU = 웹/자서전 사용자 · WF = 웹/가족 · WA = 웹/관리자
와이어프레임 번호
화면 내 원형 번호는 우측 요소 설명표의 No.와 1:1로 대응합니다
충실도
본 문서는 레이아웃·정보구조 정의를 위한 Low-fidelity 와이어프레임이며, 실제 비주얼 디자인은 BI가이드를 따릅니다
접근 권한 태그
화면 상단 태그로 로그인 필요 여부, 역할별 접근 범위를 표기합니다
v1.1 변경사항 — 사진 기반 자동 회고 트리거 기능 반영. 가족·당사자 누구든 업로드한 신규 사진이 미회고 큐에 자동 등록되어 다음 대화 세션(자서전 작가 모드·말벗돌봄 모드 공통)에서 우선 제시되며, 회고 결과는 해당 시기 챕터 본문에 자동 인라인 편입됩니다. 이에 따라 M3·M4·WU2·WF3 화면이 갱신되었고, 당사자의 모바일 사진 촬영·업로드를 위한 M7(사진 추가하기) 화면이 신규 추가되었습니다 (기획서 4.4, 프로세스 흐름도 2.5·5.7 참조).
v1.2 변경사항 — 디바이스 사양 기반 설치모드 자동 분기 반영. 앱 설치 시점에 단말 사양(RAM·OS 버전)을 자동 체크해 저사양·재활용 단말은 키오스크 모드로, 고사양 단말은 일반 앱 모드로 설치되며 두 모드의 기능은 완전히 동일합니다. 이에 따라 M1(온보딩) 설명이 갱신되었고, 관리자가 기기별 설치모드·사양을 조회하는 WA6(기기 관리) 화면이 신규 추가되었습니다 (기획서 3.7, 프로세스 흐름도 3.6 참조).
