# 벤치마크 오디오 픽스처

`docs/03-check/ondevice-slm-benchmark-protocol.md` §2 "테스트 픽스처" 참조.

여기에 16kHz mono PCM(`.pcm`, 헤더 없는 raw 샘플 — WAV가 아님) 오디오 파일을
넣으면 `RealDeviceBenchmarkTest`가 파일명 정렬 순서대로 대화 턴으로 읽어들인다.

- 어르신 구술을 흉내낸, 실제 노년층 발화 속도·억양이 반영된 샘플이어야 의미가 있다
  (성우/일반 화자 낭독은 STT 난이도를 과소평가할 위험).
- 최소 5~10개, 각 5~20초 분량 권장 — 프로토콜 문서 §2 표 참조.
- 파일이 하나도 없으면 `RealDeviceBenchmarkTest`는 실패가 아니라 **스킵**된다.

이 디렉터리 자체는 git에 커밋되지만(이 README 덕분에), 실제 오디오 파일은 개인정보
소지 여부와 무관하게 리포지토리에 커밋하지 않는다 — 로컬에만 두거나 별도 사설
스토리지에서 받아온다.
